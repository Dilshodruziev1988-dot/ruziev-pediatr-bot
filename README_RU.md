# RuzievPediatrbot — стартовый проект

## Возможности
- Двуязычное приветствие: узбекский и русский.
- Кнопки Telegram-канала и двух Instagram-страниц.
- Выбор языка.
- Административная команда `/post uz Текст` или `/post ru Текст` для публикации сообщения в канал.

## Безопасность
1. Отзовите токен, который ранее отправляли в чат, через @BotFather командой `/revoke`.
2. Новый токен добавляйте только в переменные окружения хостинга, не в исходный код и не в GitHub.
3. Не отправляйте токен в переписку.
4. Узнайте свой Telegram numeric user ID и укажите его в `ADMIN_IDS`.
5. Добавьте бота администратором своего канала с правом публикации сообщений.

## Запуск локально
1. Установите Python 3.11 или новее.
2. Создайте виртуальное окружение и установите зависимости:
   `pip install -r requirements.txt`
3. Задайте переменные окружения `BOT_TOKEN`, `ADMIN_IDS`, `CHANNEL_ID`.
4. Запустите: `python bot.py`

## Облачный запуск
Разместите проект в приватном GitHub-репозитории и подключите его к облачному хостингу, который поддерживает постоянные фоновые процессы (например, Render Background Worker).
- Build command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- Добавьте переменные окружения `BOT_TOKEN`, `ADMIN_IDS`, `CHANNEL_ID` в панели хостинга.
- Выберите платный постоянно работающий тариф, если бесплатный план может приостанавливать процесс.
- Проверьте логи после деплоя и отправьте боту `/start`.

## Публикация в канал
После того как бот добавлен администратором канала, отправьте ему в личные сообщения:
`/post uz Yangi foydali post matni`
или
`/post ru Текст новой полезной публикации`

## Ограничения стартовой версии
Выбор языка хранится в памяти процесса и сбрасывается при перезапуске. Автоматический календарь публикаций, база данных и статистика подписчиков пока не подключены. Их можно добавить следующим этапом.
